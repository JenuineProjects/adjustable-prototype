# AdjustAble: app prototype for Jacks Manufacturing Ltd

This is an interactive prototype of a workplace adjustment passport and request app. It has two views, one for employees and one for line managers. It was made for a college group project, *Harnessing Neurodiversity in the Workplace* (Assessment 1).

Jacks Manufacturing Ltd, its staff, its data and its policies are all fictional. Any data you enter is stored only in your own browser.

To try the prototype, open the GitHub Pages site for this repository. Use the switch at the top to change between **Employee** and **Line manager**.
